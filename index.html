    أقسام الدرس
      01

      ماذا يفعل هلّق البرنامج؟

      تخيّل إنك تفتح صندوق شطرنج جديد. أول شي بتسوّيه إنك ترتّب القطع على الرقعة بشكل البداية: ملك، وزير، قلوب، خيل، فيلة، وبيدق في كل خانة من الصفّين الأولين. هاي بالضبط اللي يسوّيه هلّق البرنامج: يجهّز رقعة شطرنج بحجم 8×8 ويطبعها على الشاشة بترتيب البداية.

      بس انتبه: هلّق إحنا بنجهّز الرقعة ونطبعها، ولسّا ما صرنا نلعب. يعني ما في تحريك قطع، ما في أدوار، ما في checkmate. هلّق فقط بنشوف كيف البرنامج يبني الرقعة ويعرضها على الطرفية (Terminal).

      ملاحظة مهمة هلّق البرنامج ليس لعبة شطرنج كاملة. هو فقط يجهّز ويعرض رقعة البداية. ما فيه قواعد تحريك، ما فيه أدوار لعب، وما فيه التحقق من حركة القطع.

      ليش إحنا بنعمل هيك؟

      عشان كل فنكشن (دالة) تكون مسؤولة عن شغلة واضحة: وحدة تجهّز، وحدة تلوّن، وحدة تحطّ القطع، وحدة تطبع. هلّق بنتعلم كيف نفصل المسؤوليات — وهادي أهم مهارة في البرمجة.

          03
          
      الحجارة اللي بنبني منها
      
        
      
        
      قبل ما ندخل بالرقعة، خلّينا نفهم الأدوات الأساسية في C++ اللي بيستخدمها البرنامج. ما بدي أشرح كل شي، بس بدي تفهم اللي بنحتاجه هلّق.
      

        
      المكتبات والـ #include
      
        
      تخيّل إنك بتبني بيت. محتاج أدوات قبل ما تبدأ. في C++، المكتبات هي الأدوات. #include معناها "ضيّف لي هالأدوات".
      
        
      #include <iostream>  // للإخراج على الشاشة (cout)
#include <string>     // للتعامل مع النصوص (string)
      
        
      <iostream> في فيها cout اللي بنطبع بيه على الشاشة. و<string> فيها نوع string للنصوص مثل "CHESS".
      

        
      using namespace std;
      
        
      عشان ما نكتب std::cout كل مرة، بنكتب هالسطر مرة وحدة بالأول، وبعدها نكتب cout على طول. هلّق بتوفر وقت وكتابة.
      
        
      using namespace std;
      

        
      الثابت const int SIZE = 8;
      
        
      رقعة الشطرنج دائماً 8×8. فبدل ما نكرّر رقم 8 في كل مكان، بنخزّنه في ثابت اسمه SIZE. كلمة const معناها "ما في تغيير" — إذا حدا حاول يغيره، البرنامج بيعترض.
      
        
      const int SIZE = 8;
      
        
      ليش؟ عشان لو بغينا نغيّر حجم الرقعة، نغيّر رقم وحدة بس، وكل البرنامج يتحدث تلقائياً.

      الفرق بين 'P' و "CHESS"
      
        
      انتبه لهالفرق المهم:
      
        
        
          
      • 'P' — حرف واحد، بين علامات تنصيص مفردة ' ' — نوعه char
        • 
          
      • "CHESS" — نص كامل، بين علامات تنصيص مزدوجة " " — نوعه string
        • 
        
      
        
      ما تخلط بينهم! 'P' حرف واحد، و"P" نص فيه حرف واحد. في الذاكرة، كل وحدة بتتعامل بشكل مختلف.
      

        
      معنى ' ' (المسافة)
      
        
      المسافة ' ' هي حرف مثل أي حرف! يعني 'A' حرف، و' ' كمان حرف — بس ما بتشوفه بالعين. في البرنامج، الخانات الفاضية على الرقعة بنخزّن فيها مسافة ' '، مو "لا شي".
      

        
      الحرف '0' مختلف عن الرقم 0
      
        
      انتبه! '0' (بين علامات تنصيص) هو حرف، رمزه في الكمبيوتر رقم 48. أمّا 0 (بدون علامات) هو العدد صفر. هادي مش نفس الشي!
      

        
      true و false
      
        
      النوع bool بس بقيمتين: true (صح) أو false (خطأ). بنستخدمه للأشياء اللي بتفتح أو بتسكر: "هل نطبع العنوان؟" true. "هل نطفي الألوان؟" false.

      الفهرسة من الصفر (Zero-based indexing)
      
        
      في C++، المصفوفات بتبدأ من الفهرس 0 مو من 1. يعني أول عنصر في المصفوفة هو arr[0]، وآخر عنصر هو arr[7] (في مصفوفة حجمها 8).
      

        
      جرّب بنفسك — اضغط على أي خانة
      
        
      اضغط على أي خانة في الرقعة تحت، وشوف معلوماتها بالتفصيل. تقدر كمان تستخدم أسهم الكيبورد للحركة.
      
        
      
          
      
          
      
            
      
              
      اضغط على أي خانة لرؤية تفاصيلها...
      
            
      
          
      
        
      
        
      
          انتبه، رقم الصف جوّا المصفوفة غير الرقم اللي بنطبعه جنب الرقعة

          06
          
      تجهيز الرقعة: prepareBoard
      
        
      
        
      هون إحنا بنجهّز البيانات، ولسّا ما طبعنا إشي. الفنكشن بتمرّ على كل خانة وتحطّ فيها مسافة ' '، وبعدين بتعبي أرقام الصفوف وأحرف الأعمدة.
      
        
      void prepareBoard(char board[SIZE][SIZE],
                  int ranks[SIZE],
                  char files[SIZE])
{
    for (int row = 0; row < SIZE; row++)
    {
        ranks[row] = SIZE - row;
        files[row] = 'a' + row;

        for (int col = 0; col < SIZE; col++)
        {
            board[row][col] = ' ';
        }
    }
}
      
        
      شفت عندنا حلقتين for، وحدة جوّا التانية؟ هاي اسمها حلقات متداخلة (nested loops). الخارجية بتمرّ على الصفوف، والداخلية بتمرّ على الأعمدة. الصف الخارجي ما يتقدم إلا بعد ما الصف الداخلي يخلّص كل الأعمدة الثمانية.
      

        
      الأرقام والأحرف
      
        
      انتبه لسطرين مهمّين:
      
        
      ranks[row] = SIZE - row;      // row=0 → 8, row=1 → 7, ... row=7 → 1
files[row] = 'a' + row;       // row=0 → 'a', row=1 → 'b', ... row=7 → 'h'
      
        
      السطر الأول بيحسب رقم الصف المعروض: الصف 0 في المصفوفة هو الصف 8 في العرض. ليش؟ لأن رقعة الشطرنج بتبدأ من الأسفل، فالصف اللي فوق (index 0) هو رقم 8.
      
        
      السطر الثاني بيستخدم حساب الحروف: 'a' + 0 = 'a'، 'a' + 1 = 'b'، 'a' + 2 = 'c'... هاي لأن الحروف في C++ بتتعامل كأرقام (ASCII). بس انتبه: هاي بتشتغل لأن الحروف الإنجليزية متتالية في ASCII. ما نفترض إن كل ترميز بيضمن هاي الخاصية.

      ألوان الخانات: colorBoard
      
        
      
        
      رقعة الشطرنج خاناتها بتتناوب بين أبيض وأسود. بس كيف البرنامج بيعرف كل خانة أيّ لون؟ السرّ في عملية اسمها الباقي بعد القسمة — علامة %.
      

        
      الباقي بعد القسمة %
      
        
      تخيّل إنك تقسّم 10 على 3. الناتج 3 والباقي 1. علامة % بتعطيك الباقي: 10 % 3 = 1. وكذا: 4 % 2 = 0، 5 % 2 = 1، 6 % 2 = 0.
      
        
      لاحظ: أي عدد زوجي قسمته على 2 بيطلع باقيه 0، وأي عدد فردي باقيه 1. هلّق بنستخدم هاي الفكرة!
      

        
      تطبيقها على الرقعة
      
        
      if ((row + col) % 2 == 0)
{
    colors[row][col] = WHITE_SQUARE;
}
else
{
    colors[row][col] = BLACK_SQUARE;
}
      
        
      بنجمع رقم الصف ورقم العمود، ونقسم على 2. لو الباقي 0 ← خانة بيضا. لو 1 ← خانة سودا. هلّك بيخلّي الخانات بتتناوب تلقائياً!

      وضع القطع على الرقعة
      
        
      
        
      هلّق الرقعة جاهزة وملوّنة، بس فاضية. لازم نحطّ القطع! البرنامج بيفصل بين القطع البيضاء والسوداء في فنكشنين منفصلين.
      

        
      القطع البيضاء: placeWhitePieces
      
        
      void placeWhitePieces(char board[SIZE][SIZE])
{
    char pieces[SIZE] = {'R', 'N', 'B', 'Q', 'K', 'B', 'N', 'R'};

    for (int col = 0; col < SIZE; col++)
    {
        board[6][col] = 'P';
        board[7][col] = pieces[col];
    }
}
      
        
      القطع البيضاء بتروح على صفّين: البيداق على الصف 6 (اللي بيتعرض برقم 2)، والقطع الرئيسية على الصف 7 (اللي بيتعرض برقم 1).
      

        
      القطع السوداء: placeBlackPieces
      
        
      void placeBlackPieces(char board[SIZE][SIZE])
{
    char pieces[SIZE] = {'r', 'n', 'b', 'q', 'k', 'b', 'n', 'r'};

    for (int col = 0; col < SIZE; col++)
    {
        board[0][col] = pieces[col];
        board[1][col] = 'p';
    }
}
      
        
      القطع السوداء بتروح على الصف 0 (رقم 8) والبيداق على الصف 1 (رقم 7).

    blackPlayer = config.blackPlayerName;
}
      
        
      شفت علامة & قبل اسم المتغير؟ هاي معناها "مرجع". يعني الفنكشن ما بتنسخ القيمة، بتعمل رابط للمتغير الأصلي اللي في main. أي تغيير تسوّيه الفنكشن، بيظهر على المتغير الأصلي.
      

        
      تخيّلها هيك
      
        
      فكّر إنه عندك صندوق اسمه whitePlayer في غرفة main. لو بعتّ نسخة من الصندوق لفنكشن، الفنكشن بتغيّر النسخة، والأصلي يبقى نفسه. بس لو عملت مرجع، الفنكشن بتشوف نفس الصندوق الأصلي وتغيّر فيه مباشرةً.

      ألوان الطرفية: شرح أكواد ANSI
      
        
      
        
      الطرفية (Terminal) ما عندها واجهة رسومية. بس فيها سرّ: لو بعتلها سلسلة معينة من الحروف، بتفسرها كأمر للتلوين، مش كنص عادي. هاي الأكواد اسمها ANSI escape codes.
      

        
      ثلاث مفاهيم منفصلة
      
        
      
          
      
            
       1. الحرف
      
            
      الحرف المخزّن في board — مثل 'R' أو ' '.
      
          
      
          
      
            
       2. لون الخلفية
      
            
      لون الخانة نفسها — بيتحدد من setSquareBackground.
      
          
      
          
      
            
       3. لون النص
      
            
      لون الحرف — بيتحدد من setPieceColor.
      
          
      
        
      

        
      تفكيك الكود
      
        
      خلّينا نفكك كل جزء من كود ANSI:
      
        
      cout << "\033[48;5;" << background << "m";
      

        
      \033[48;5;247m
      

        
        
          
      • \033 — حرف الهروب (Escape). بعث رسالة للطرفية: "عندك أمر خاص، مش نص". مكتوب بصيغة ثمانية (octal).
        • 
          
      • [48;5; — 48 معناها "غيّر لون الخلفية"، ;5; معناها "استخدم نظام 256 لون".
        • 
          
      • 247 — رقم اللون من 0 إلى 255. هلّق 247 = رمادي فاتح.
        • 
          
      • m — نهاية الأمر. بيقول للطرفية "انتهى كود التحكم".
        •

          ليش رمادي، مو أبيض وأسود نقي؟
          لو خليت الخلفية بيضا نقية (255) والنص أبيض (97) — ما بتشوف النص! ولو خليت الخلفية سودا نقية (0) والنص أسود (30) — كمان ما بتشوفه. الرمادي بيخلّي القطع البيضا والسودا كلاهم شوفها. بس انتبه: لو غيّرت الألوان لقيم سيئة، التباين ممكن يخرب.
        
      

        
      إعادة الضبط \033[0m
      
        
      هلّق لازم نرجّع الطرفية لحالتها الطبيعية بعد كل خانة. لو ما عملنا reset، اللون بيكمل للنص اللي بعده!

       r  n  اسم اللاعب الأسود ← بعد reset، رجع طبيعي

      لون النص: setPieceColor و isWhitePiece
      
        
      
        
      هلّك عندنا فنكشن صغيرة بس مهمة: isWhitePiece. بتشوف إذا الحرف كبير (A–Z) أو صغير (a–z).
      
        
      bool isWhitePiece(char piece)
{
    return piece >= 'A' && piece <= 'Z';
}
      
        
      && معناها "و" (AND). يعني: الحرف لازم يكون >= 'A' وفي نفس الوقت <= 'Z'. لو الشرطين صح، يرجع true.
      
        
      
          انتبه
          isWhitePiece بتشوف بس إذا الحرف كبير. ما بتتحقق إذا كان حرف قطعة شطرنج صحيح. يعني لو أعطيتها 'X'، بترجع true!
        
      

        
      اختبر بنفسك
      
        
      
          
          
          
      النتيجة: true — قطعة بيضاء
      
        
      

        
      setPieceColor
      
        
      void setPieceColor(char piece, SquareColor color, const Config &config)
{
    bool whiteText;

    if (config.colorPieces)
    {
        whiteText = isWhitePiece(piece);
    }
    else
    {
        whiteText = (color == BLACK_SQUARE);
    }

    if (whiteText)
    {
        cout << "\033[97m";  // نص أبيض
    }
    else
    {
        cout << "\033[30m";  // نص أسود
    }
}

      القطع السوداء (صغيرة) ← نص أسود.
      
            
      اللون بيعتمد على اللاعب.
      
          
      
          
      
            
       colorPieces = false
      
            
      الخانة البيضا ← نص أسود.
      الخانة السودا ← نص أبيض.
      
            
      اللون بيعتمد على الخانة.
      
          
      
        
      
        
      
          ملاحظة
          لو enableColors = false، فنكشن printSquare ما بستدعي أصلاً فنكشنات التلوين. يعني colorPieces ما إلها تأثير لو الألوان مطفية.

      الرمز المعروض: getSquareSymbol
      
        
      
        
      هلّك عندنا قرار مهم: شو الحرف اللي بنطبعه في كل خانة؟ الفنكشن بترجع حرف، ما بطبعه بنفسها.
      
        
      char getSquareSymbol(char piece, SquareColor color, const Config &config)
{
    if (piece != ' ' || config.enableColors)
    {
        return piece;
    }

    if (color == WHITE_SQUARE)
    {
        return config.lightSquareSymbol;
    }

    return config.darkSquareSymbol;
}
      

        
      مخطط القرار
      
        
      عندنا شرط واحد أساسي: piece != ' ' || config.enableColors. علامة || معناها "أو" (OR). يعني: لو في قطعة، أو لو الألوان مشغّلة ← رجّع الحرف نفسه.
      

        
      
          
      
            الشرط: piece != ' ' || config.enableColors
          
      
          
      
            صح ✓ ← رجّع piece (الحرف نفسه)
          
      
          
      
            خطأ ✗ ← يعني الخانة فاضية و الألوان مطفية
          
      
          
      
            لو color == WHITE_SQUARE ← رجّع config.lightSquareSymbol (افتراضي: '.')
          
      
          
      
            غير هيك ← رجّع config.darkSquareSymbol (افتراضي: ':')

      سوء فهم شائع
      
        
      
        
      خلّينا نصحّح أخطاء كثير بيقع فيها المبتدئين:
      

        
      
          
       "الفهرس يبدأ من 1"
      
          
      لا! في C++ المصفوفات بتبدأ من 0. board[0][0] هو أول خانة، وboard[7][7] هو آخر خانة. بس الأرقام اللي بنطبعها جنب الرقعة (ranks) بتبدأ من 8 وتنزل لـ 1.
      
        
      

        
      
          
       "الصف 0 هو الصف 1"
      
          
      لا! الصف 0 في المصفوفة هو اللي بيتعرض برقم 8 (لأن ranks[0] = 8 - 0 = 8). الصف 7 هو اللي بيتعرض برقم 1.
      
        
      

        
      
          
       "WHITE_SQUARE يعني قطعة بيضاء"
      
          
      لا! WHITE_SQUARE بيوصف الخانة، مو القطعة. الخانة البيضا ممكن فيها قطعة سودا، والعكس.
      
        
      

        
      
          
       "colorPieces = false بيشيل القطع"
      
          
      لا! بغيّر بس لون النص. القطع تضل مكانها. لو بدك تشيل القطع، اطفي showWhitePieces أو showBlackPieces.
      
        
      

        
      
          
       "enableColors = false بيمسح القطع"
      
          
      لا! بيطفي بس التلوين. القطع تضل موجودة، بس الخانات الفاضية بتظهر برموز . و : بدل ما تكون ملونة.
      
        
      

        
      
          
       "اطفاء showWhitePieces بيخفي القطع بس"
      
          
      لا! الفنكشن placeWhitePieces ما بتنادي أصلاً. يعني القطع ما بتتحط في الذاكرة. مو بس مخبية — مش موجودة.
      
        
      

        
      
          
       "getSquareSymbol بتطبع الحرف"
      
          
      لا! بترجع الحرف بس. اللي بطبعه هو printSquare لما ياخد النتيجة ويبعتها لـ cout.
      
        
      

        
      
          
       "colorBoard بتطبع ألوان"
      
          
      لا! بتعبي مصفوفة colors بقيم منطقية (WHITE_SQUARE / BLACK_SQUARE). التلوين الفعلي بيصير بعدين في printSquare.
      
        
      

        
      
          
       "setSquareBackground بيغيّر colors"
      
          
      لا! بيبعت كود ANSI للطرفية بس. ما بلمس مصفوفة colors. هي بتقرأ من config وتطبع.
      
        
      

        
      
          
       "هاي لعبة شطرنج كاملة"
      
          
      لا! ما فيه تحريك، ما فيه أدوار، ما فيه checkmate. البرنامج بجهّز وبيطبع رقعة البداية فقط.
      
        
      

        
      
          
       "Config ملف على القرص"
      
          
      لا! Config مجرد struct في الذاكرة. ما فيه قراءة من ملف. القيم الافتراضية مكتوبة في الكود.
      
        
      

        
      
          
       "هالصفحة بتشغل C++"
      
          
      لا! هاي محاكاة بـ JavaScript عشان تعلمك. الكود الأصلي C++ بيشتغل في طرفية حقيقية. إحنا بنحاكي سلوكه للتعليم.
